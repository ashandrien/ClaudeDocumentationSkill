# Markdown docs

This covers README files, architecture notes, `CLAUDE.md`, and skills. Write them following `prose.md`.

## When a doc should exist

Add Markdown docs when there's a real gap to fill. Before creating a new `.md` file or growing an
existing one, check whether trimming or editing what's there would do the job.

## Editing an existing doc

Edit it so it reads as one coherent piece, as `prose.md` describes: put new content where it belongs,
rewrite nearby text to fit, and remove what the change makes redundant.
